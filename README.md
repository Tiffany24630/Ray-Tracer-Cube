# Ray-Tracer-Cube
## Cómo correr

1. Clonar el repositorio y cambiar a esta rama:
    ```bash
    git clone https://github.com/Tiffany24630/Ray-Tracer-Cube.git 
    cd Ray-Tracer-Cube
    ```

2. Compilar y ejecutar:
    ```bash
    cargo run
    ```
